## 这条路线在游戏里干什么

每天进迷宫走到流浪商人（蓝松鼠），在他店里把目标商品（强化石，以及几种书签 / 友情点数）买走，
然后放弃战斗回大厅。走迷宫有两段赶路、控件会淡入，期间认不出东西只许等、不许收工；
**只有亲眼确认商店里已经没有可买的强化石了，才算做成、才能正常回家**。迷宫不花门票，商店
当天没刷出目标商品是正常结局。放弃战斗是不可逆动作，靠「看得见的事实或有界重试走完」才放行。

## 页面链路

```
大厅 → 战斗菜单「一般」页 → 迷宫卡片 → 迷宫列表 → 详情页（选中 1 区域）→ 选择队伍 → 战斗开始
  → 十字路口房间（开地图 → 拖到出口 → 传送）→ 落地房（往西走）→ 流浪商人商店
  → 退出商店 → 暂停菜单 → 放弃战斗 → 详情页 → 酒馆 → 大厅
```

- 迷宫详情页会来两次（进场前 / 放弃后），长得一样、下一步相反，靠跨帧进度标记区分。
- 「一般 / 赛季 / 第三个标签页」由上次停在哪个页签决定，游戏会记住，不是固定从「一般」进。
- 商店里当天没有可买的目标商品是**正当收工**，不是失败。

## 判据为什么这么设计

每条写的是「靠哪一维排除外观同类、语义不同的对象」，不是调阈值的经验值。

- **「没看见」永远不能当放弃的理由**：房间判据原来是「没看见开地图的蓝菱形 ⇒ 认输 ⇒ 放弃」，
  而进迷宫有走路 / 过场，控件还在淡入，菱形模板在走路帧分数很低 ⇒ 刚进迷宫就放弃、日志还写
  「已完成一遍」。判据因此分三类、不许混：走路 / 淡入期间认不出锚点 = **还没到** ⇒ 抛
  `UnrecognizedScreen` 等、绝不放弃；商店确认没有可买的强化石 = **做成了**（唯一正当收工）；
  有界重试走完 / 撞上真战斗 = **做不成** ⇒ 回家 + 记真实原因 + Runner 报错。⇒ 「没看到」和
  「没出现」在画面上分不开，**认不出必须单列「未知 / 还没到」，绝不并入「做成了」**，
  `score=None` 是关键信号。⇒ **回家 ≠ 完成**：`_check_cycle_completed` 拿 `blocked_reason`
  卡一道闸，非空就报错，绝不写「已完成一遍」；`_open_pause` 的 docstring 写死了只有两处能调它。
- **半透明 / 会淡入的蓝色控件：靠颜色存在性、不靠亮度**：W 徽记半透明，大模板在落地房分数低、
  换小模板才过阈；某间房根本没有 W 徽记 ⇒「点不到 W」是**还在走路**，要等，不是收工理由。
  开地图那颗蓝菱形也半透明 ⇒ 两条判据取**或**（模板过阈 **或** 蓝色块占比过阈），且蓝色块判据
  **只看色相 / 饱和度、不看亮度**，免得又被淡入骗一次。⇒ 量分必须走生产口径 RGB：
  `load_template` 把模板转成 RGB，用 BGR 直喂会凭空掉分；`TM_CCOEFF_NORMED` 对整体乘性亮度
  不变，别拿「压暗」解释掉分。
- **商店买什么过三道关**：① 这一行类别标签写着「强化石」（类别在按钮上方、配对容差内）；
  ② 商品名里有「石」字；③ 按钮上还亮着白字（**数一片白字像素**，不是取极值）。①②**缺一不可**：
  事故那次是①单独失灵（类别→按钮偏移方向写反，每行拿下一行的类别判断自己，把「强化拳套」
  当成强化石买走，花的是真金白银）；③ 被真机事故逼着改过两次，先「相对亮度」→ 被压暗骗，
  再「最亮一颗」→ 被一颗游离白像素骗，现在收进模板 footprint 数够不够多。
  ⇒ **别改回任何一种「取极值」的写法，极值天然只有一颗像素的鲁棒性**；配不上对的行一律不点。
  ⇒ **判据对了不等于断言对了**：原来那条测试断言的是友情点数的按钮，一直在为「买错东西」
  背书；断言值必须能说清「这一行到底是什么商品」（用 OCR 逐行读出来才核对出来的）。
- **目标商品两类走两把尺**：强化石走「类别写着强化石 + 名字带石」两道文字锁；友情点数 / 圣约
  书签 / 神秘书签走**商品图标**（借 `templates/shop_refresh/` 的图，与秘密商店同一个商品、同一
  张图，不另存第二份）—— **类别标签会随商店变、图标不变**。按钮上有没有白字（没卖完）是
  共同的最后一道锁；认不出只是少买、不会误买。
- **不是本路线点出来的购买确认框一律按取消**（`buy_armed`）：认不出买的是什么就绝不替人按
  「确定」。
- **页面身份靠「哪个标签被选中」，不靠「赛季有没有被选中」**：游戏会记住上次停在哪个标签页。
  旧口径「顶栏标题在 且 赛季没被选中」⇒ 第三个标签页同样满足、被当成一般页（满分）⇒ 迷宫
  在第三页上找不到那几张卡片 ⇒ 超时。修法按选中态分三页（一般 / 赛季 / 都不是），三条链的
  第一跳都接纳新落点。⇒ **为什么不认第三个标签的文字**：它会变（两帧逐像素看过，写的不是
  同一个词）⇒ 按位置 / 选中态分页才稳，**模板里不放会变化的内容**。⇒ **三条判据的顺序是
  判据的一部分、不能重排**：`battle_general_active` 必须第一个判；「第三页」那条必须排在
  `battle_menu` 之后（它用的「赛季没被选中」在一般页上也过阈）。
- **「切回一般页」锚点两张候选**：「一般」标签在赛季页与第三页底纹不同，一张候选在另一来源
  页差一点点不到阈 ⇒ 两张候选各管一个来源页（任一过阈即命中，语义同 `lobby_shop_entry` /
  `novice_arena`）。敢「哪张胜出都行」：锚点区域只比模板大一点点 ⇒ 命中中心恒在同一格内，
  这一步不需要固定坐标。
- **EVENT 标会挂到别的入口**：`lobby_battle` 旧模板把「战斗」上方那条 EVENT 标也裁了进去，
  标挂到了「竞技场」上方那一格就空着 ⇒ 分数掉到中档、整条路线连点都没点就结束。修法是
  模板只裁「战斗」二字。⇒ 分诊「缺少导航锚点 X」：先看那张模板里有没有放会变的东西
  （活动标 / 数值 / 头像 / 段位字），再看阈值 —— 「模板内容变了」的指纹是分数掉在中档，
  「场景换了」会掉到极低档。
- **回家流程不许把同一招重试到超时**：商店页对导航层是 `unknown`、蓝色四格被浮层盖着模板却
  照样命中 ⇒ 每轮点它一次空等、同一招重复到超时，违反「未登记页必须有有界逃生门」。⇒「重看
  一遍」≠「重试同一招」：连续两次无效即停用该动作、落到 ESC 兜底（见 `games/epic7/home_return.py`
  模块 docstring）。⇒ **真正的修法永远在上游**（让路线自己正常走完），别指望回家流程擦屁股。
  ⇒ 分诊「回首页失败 / 超时」：若同一动作的置信度反复是同一个数字，几乎可以断定是**判据在
  这页不成立**（控件被盖住 / 被压暗），不是转场慢（转场慢置信度会跳）。
- **房间与真战斗、详情页两次**：迷宫房间会被「战斗中」判据误报，房间与真战斗靠士气笑脸 / 战斗
  回合条分开，且 `battle` 页必须排在 `room` 前面；详情页两次靠 `entered` 跨帧标记区分，接力
  落在迷宫里必须显式标记进度。

## 危险边界

- **买东西花真金白银、放弃战斗不可逆**：误买过「强化拳套」。拦误点靠三道锁（类别 + 石字 +
  白字）缺一不可、配不上对一律不点、`buy_armed` 只对自家确认框放行、认不出少买不误买。
  放弃战斗只在「商店确认没得买」时才收工，「没看见」永不作理由，回家 ≠ 完成。
- **迷宫不花门票**，所以随时可实跑验证；代价只是少买一次，收尾走「下滑几次 → 离开」的正当分支。
- **收尾汇报报不出金额是用户当面拍板的口径**：金额读取（字模 / OCR / 不做三选一）、单价上限
  都**先不做**，别擅自开工；真要做那天再补。
- 认不出 / 超时 → 安全停止留证，不猜着继续点，见
  [TRANSITION_CONTRACTS.md](../TRANSITION_CONTRACTS.md)；全局危险动作与拦截机制见
  [SAFETY_MATRIX.md](../SAFETY_MATRIX.md) 第一节；**不许为了过单张截图降阈值**。
