## 这条路线在游戏里干什么

赛季玩法：从大厅「战斗」进赛季页，打开「远征队」看手里的通缉传单，挑一张、确认难度（难度三已选中就直接确认）、编队出发打，打完伤害直接进结算，再走公开招募看结果，最后返回主页；传单用完就收工。**这条路线没有「输」**——打完伤害一律进结算，不存在需要单独识别的「战败页」。

## 页面链路

```
大厅「战斗」→ 赛季页 → 远征队（传单列表）→ 难度选择 → 队伍准备 → 战斗
           → 结算 → 公开招募（结果）→ 返回主页 → 传单列表 …
```

- 传单用完时游戏显示「未持有通缉传单」，这是**收工信号**（`PostersExhausted`），不是异常分支。
- 赛季页那排卡片内容随赛季阶段变；「远征队」只是进入下一跳的点击目标，不参与页面判定。

## 判据为什么这么设计

每条写的是「靠哪一维排除外观同类、语义不同的对象」，不是调阈值的经验值。

- **「未持有通缉传单」`empty_posters`**：模板只取固定文案「未持有通缉传单。完成讨伐中级以上将有一定几率获得。」——**零可变内容**，不含持有数与倒计时。靠「固定文案」这一维区分「没有传单」与「有传单的列表页」：后者分数低，证明模板在区分**两种状态**，不是单纯认列表页。裁法见 [TEMPLATE_CAPTURE.md](../TEMPLATE_CAPTURE.md)。
- **缺模板必须响亮地失败**：三道关——加载期用 `load` 而非 `load_optional`（缺文件点名报错）、证据画像 `required=True` 校验、运行期 `_locate` 对非白名单的 `None` 抛错。⇒ 收工判据一旦缺文件，不许安静给个 `None` 让路线继续找那个永远不会出现的出发按钮、一路干等到超时。
- **「可选」不是「先这样、以后再补」的口子**：`empty_posters` 就是这么丢的（登记成「可选」、模板从没做、漏判到超时）；当年测试还用假图顶替、并断言 `templates.empty_posters is None`，把缺陷当成预期行为。⇒ **新增锚点必须同时补模板文件**。
- **远征没有「输」这回事（用户口径）**：`defeated_confirm` 判据整个删除。用户当场质疑「之前完全没用过呀，也没问题呀」，并说明机制：打完伤害直接进结算，所有情况同一类。⇒ 它不是「缺一张图」，是**这条路线根本没有这个页面**；留着的代价是多一个永远为 `None` 的判据、一处「可选」口子、一份要维护的假分支。相关动作、状态判断与特殊分支一次清干净。
- **白名单机制保留、内容清空**：它是防静默降级的护栏，不能因为没人用就拆掉；清空后语义反而更强——**远征一张模板都不许缺席**（回归逐个把模板置 `None`，断言 `_locate` 必须报错点名）。
- **赛季页判据摘掉「远征队」卡片：一条锚点不许身兼两职**：`expedition_entry` 本职是「进入远征队」那一跳的**点击目标**，当初被顺手塞进页面判据（三锚点合取）。而那排卡片内容**随赛季阶段变**，换季后掉分 ⇒ 三缺一 ⇒ 整页认不出，连月塔都被拦在门外（它自己的标题锚点其实没坏）。⇒ **页面判据只由页面骨架（标题 +「赛季」高亮条）构成**，点击目标降级为纯点击目标、保留但不参与判定；「一般」页同理。
- **反向护栏必须同时证伪**：只断言「整页认得出」抓不住回归——把卡片重新绑回判据、只要帧恰好没换季也照样过。必须**同时**断言「卡片这张帧上确实认不出」；把锚点塞回去后护栏立刻变红，确认不是空护栏。见 `tests/test_navigation.py`。
- **`battle_general_tab` 认错了对象（已单独立项、未修）**：名字像「一般」标签，模板其实是从**赛季高亮条**上裁的，在「一般 | 赛季(蓝色高亮) | 活动」那张帧上照样满分。后果：游戏记住上次停在赛季 tab、实际落在赛季页时被判成「一般」页 ⇒ 去点「一般」那一栏（实际是「赛季」）⇒ 点了没反应。原注释把根因记成「没有下一步可走」，实为**页面判错**；下次处理要重裁为真正的「一般」二字未选中态。

⇒ 通用结论：**模板不含会变内容**（持有数、倒计时、赛季卡片）；**判据要能证伪**（分离度要区分两种状态，反向护栏同时钉住正反两面）；**一条锚点不许身兼两职**（页面骨架 vs 点击目标）；**缺模板要 fail loud**，不许静默降级。

## 危险边界

- **这条路线会花资源**：出发消耗通缉传单；传单用完（`PostersExhausted`）应干净收工，**不许**继续找那个永远不会出现的出发按钮、干等到超时。
- 难度三是否已选中、传单是否可出发、公开招募与返回主页都是**业务事务判断**，**不因识别分数下降就放宽难度或出发条件**；摘判据、补图都不许动这些条件。
- 「远征进入」是全局危险动作之一：认不出 / 全黑帧时只许返回 `None` 或抛 `UnrecognizedScreen`，**不许给出带坐标的动作**，见 [SAFETY_MATRIX.md](../SAFETY_MATRIX.md) 第一节。
- 「冻结不补点」是否启用**等用户拍板**：用户 2026-10-09 明确否掉过「一律禁止重试」（会把「真的没点到」也一起禁掉），按路线逐个开、不擅自扩，见 [TODO.md](../TODO.md)。
- 认不出 / 超时 → 安全停止留证，不猜着继续点，见 [TRANSITION_CONTRACTS.md](../TRANSITION_CONTRACTS.md)。
