# 英雄图鉴维护

图鉴由 `games/epic7/templates/arena/heroes_pokedex/` 的英雄头像和同目录 `meta.json` 组成。
修改前先区分英雄资料、页面布局与战斗机制，再按[游戏更新手册](../howto/game_update.md)确认涉及的客户端。

## 一、变更会影响哪里

| 变更 | 检查范围 |
| --- | --- |
| 头像、名字、职业、属性、星级 | 竞技场避战与优先名单、桌面头像与分类筛选。实跑加载用户选中的英雄，空名单沿用正常选敌逻辑。 |
| 英雄合成、刻印或传送的页面改变 | 英雄合成使用 `templates/hero/`。按[英雄合成手册](hero_synthesis.md)验真实页面和不可逆操作。 |
| 新英雄同时带来召唤页、活动剧情、额外弹窗或战斗 HUD 变化 | 确认页面实际出现在哪些路线和账号。按[游戏更新手册](../howto/game_update.md)回归对应路线或共享层。 |

已保存的名单以中文名为键。更新旧头像优先保留原中文文件名。需要改键时，在 PR 中交代旧名单如何验证或调整。
只新增一名英雄资料时，按表中第一行验收，已有跨端页面和运行状态继续按现有证据管理。

## 二、新增一名英雄（日常，一条命令）

1. 从目标区服的游戏内公告核对中文名、形态和上线版本，再确认英文名、职业、属性及星级。
   相似头像、月光形态或同前缀英雄要和对应角色实图核对。社区数据用于比对和提供候选，
   来源与素材权利按[权利声明](../../NOTICE.md)和[发行流程](../howto/release.md)复核。
2. 从仓库父目录执行，示例使用已收录英雄说明参数。日常维护替换为本次已确认的信息。

   ```powershell
   python -m auto_game_unified.tools.add_hero --zh 蕾诺娅 --en Renoa
   ```

   如果主数据源尚未分类，可传 `--job 射手 --element 火 --stars 5` 等已核对的分类。
   工具优先从 Epic7DB 取头像，找不到时用 Epic Helper 的角色头像，统一为 112×112 PNG。
3. 运行离线检查和影响预览。暂存改动后不传路径会按暂存项判断。

   ```powershell
   python -m auto_game_unified.tools.check_hero_roster
   python -m auto_game_unified.tools.check --plan
   ```

   从已确认的变更文件执行定向回归，打开桌面竞技场名单看能否搜索、勾选和筛选。
   有当前版本的竞技场对手帧时，用勾选该英雄的离线回放核对选敌，含相似头像反例。
   头像和分类在同一个 PR 审阅，并附校对来源。

### 写入保护与恢复

| 情况 | 处理 |
| --- | --- |
| 疑似已有同图、同一英文名或同名头像 | 先核对中英文名、形态和原有配置。明确是数据订正才使用 `--force`，保留证据与前后差异。 |
| 两个来源均未找到 | 可放入已核对、许可允许的同名 112×112 RGB PNG，再用 `--skip-avatar` 只补分类。 |
| 命令意外中断 | 运行离线检查，核对这一轮的头像和 `meta.json`，补齐已确认条目或在独立分支用 Git 恢复相应改动。 |
| 误改了已有英雄名称 | 先恢复原中文键。修复方案需要验证原避战和优先名单能保留含义。 |

离线工具检查头像能否解码、格式尺寸、同名条目、数量及分类字段，可用 `--library <目录>`
检查隔离样本。英雄身份和名称来源由维护者复核。

## 三、批量刷新和历史重建

`python -m auto_game_unified.tools.refresh_hero_meta --check` 用外部数据比对现有头像并打印候选与冲突。
外部站可能晚于游戏内公告。先看报告再选择 `--write`，已有类目默认保留。
使用 `--library <目录>` 时，读取和写回该目录的 `meta.json`。批量重建先在独立目录复核，
用 Git 比较本次有效变更，并在每次应用写回后重跑离线校验。查重或来源发生变化时，另开 PR 复核判据与正反例。

首次建库需要的旧配对、取证和诊断依据见 [Git 中的原记录](https://github.com/Kangkangnice/epic7-automation/blob/c935fcd244c007eb5c9d9347c9596bbb962384e5/docs/maintenance/hero_roster.md)。
维护工具的社区数据入口见 [Epic7DB 英雄目录](https://epic7db.com/heroes)与 [Epic Helper](https://epic7helper.com/)。
