# 页面转场契约

自动化中的一次点击不等于业务成功。每个会改变页面或业务状态的动作，都应当写清楚“允许从哪里点击、看到什么才算进入、看到什么才算完成、失败时留下什么证据”。这份约定用于新路线开发、现有路线审计和实机故障复盘。

## 基本原则

总原则是：**点击不等于成功**，安全结论必须明确属于 `SAFE / UNSAFE / UNKNOWN` 三态之一。

1. **点击只是候选动作**：日志只能写“已点击/等待确认”，不能在目标证据出现前写“成功”。
2. **先确认来源，再允许点击**：来源页面不明确时，不靠坐标猜测；返回 `UNKNOWN` 并保存诊断。
3. **安全判断采用三态**：
   - `SAFE`：正向证据充分，可以继续。
   - `UNSAFE`：发现明确阻断证据，必须停止或转入安全分支。
   - `UNKNOWN`：证据缺失或互相冲突，不得按 `SAFE` 处理。
4. **缺少模板时关闭危险动作**：涉及选择材料、传送、消耗资源等动作，关键模板缺失必须 fail closed。
5. **确认目标来自原事务**：重试时保留第一次点击的目标页面和业务目的，不能用当前误识别页面覆盖原目标。
6. **动态区域不能单独证明切换成功**：人物呼吸、粒子、滚动动画只能作为“发生过运动”的辅助证据；成功仍需稳定页面标志或业务状态变化。
7. **进入与退出都要稳定**：建议在连续稳定帧或等价的去抖条件满足后确认页面，避免单帧误判。
8. **循环计数只跟业务完成绑定**：点击次数、过渡动画和重试次数都不能增加完成轮次。
9. **日志必须可证伪**：记录候选动作、来源证据、目标证据、重试原因和最终结论；“未确认”不能写成“成功”。

## 契约模板

实现或审查一个动作时，复制并填写以下字段：

```text
动作名称：
来源页面：
进入正向证据：
阻断证据 / UNKNOWN 条件：
点击坐标依据：
允许目标页面：
业务成功证据：
重试条件：
失败诊断：
循环计数影响：
```

字段说明：

- **来源页面**：动作被允许执行的页面状态。
- **进入正向证据**：确认已进入来源页面的稳定视觉或状态证据。
- **阻断证据 / UNKNOWN 条件**：明确危险标志、关键模板缺失、识别冲突或证据不足。
- **点击坐标依据**：固定布局、模板中心或经窗口缩放换算后的逻辑坐标。
- **允许目标页面**：点击后可以合法抵达的页面集合。
- **业务成功证据**：能够证明业务结果已经发生的证据，而不是动画或局部变化。
- **重试条件**：来源仍成立、目标未出现且未发现危险状态时，才允许重试。
- **失败诊断**：至少保存最终截图；高风险或难复现动作应保存前后帧、裁剪区和量化指标。
- **循环计数影响**：说明何时加一，通常只有业务完成证据成立时才加一。

## 推荐日志语义

```text
动作候选 action=<name> source=<page> evidence=<summary>
执行点击 action=<name> attempt=1/4 point=(x,y) targets=<pages>
等待确认 action=<name> observed=<page> remaining=<seconds>
转场未确认 action=<name> reason=<reason> retry=<n/4>
转场确认 action=<name> target=<page> evidence=<summary>
业务成功 action=<name> result=<result> cycle=<n>
安全停止 action=<name> state=UNKNOWN diagnostic=<path>
```

“转场确认”和“业务成功”是两个不同层次。例如进入合成页面只证明页面切换完成，只有结果页出现并被正确关闭后，才证明一次合成事务完成。

## 英雄合成示例

### 切换英雄卡片

- 来源页面：英雄详情/列表中的当前英雄卡片稳定可见。
- 进入正向证据：中心选中框、详情区域和列表结构满足英雄详情页条件。
- 点击坐标依据：下一张英雄卡片的固定槽位或经过标定的逻辑坐标。
- 允许目标页面：仍为英雄详情页，但选中事务必须经历可解释的切换过程。
- 业务成功证据：过渡动态已经结束，详情页重新稳定；能区分时使用身份特征，两个副本外观相同时不能只比较英雄立绘。
- 重试条件：点击后既未观察到切换动态，也未观察到稳定目标状态，并且来源页面仍成立。
- 失败诊断：保存点击前、动态峰值帧、点击后稳定帧和各 ROI 差异指标。
- 循环计数影响：无。

### 进入合成

- 来源页面：目标英雄详情页。
- 进入正向证据：合成/记忆刻印入口可操作，页面无弹窗遮挡。
- 阻断证据 / UNKNOWN 条件：入口置灰、页面身份不明或关键模板缺失。
- 允许目标页面：合成材料选择页。
- 业务成功证据：材料区域、确认区域等合成页稳定标志同时成立。
- 重试条件：详情页仍成立且目标页未出现。
- 循环计数影响：无。

### 选择材料

- 来源页面：合成材料选择页。
- 进入正向证据：材料卡区域和确认区域稳定可见。
- 阻断证据 / UNKNOWN 条件：任一候选材料识别为 SSS，或 SSS 判断证据不完整。
- 业务成功证据：安全材料已进入选中状态；仅“看见材料卡”不等于可以点击。
- 重试条件：只能在安全判定仍为 `SAFE` 时重试。
- 失败诊断：保存材料卡原图、SSS 检测区域、匹配分数和候选排序。
- 循环计数影响：无。

### 遇到 SSS 后退出并传送副本

- 来源页面：合成页或英雄详情页，且目标英雄已确认达到 SSS。
- 进入正向证据：SSS 为稳定正向证据，不依赖单帧动画。
- 点击坐标依据：先退出合成页，再进入传送流程；每一步单独确认。
- 允许目标页面：英雄详情页 → 传送选择页 → 传送确认/完成页。
- 业务成功证据：传送完成结果出现，随后回到允许的英雄页面。
- 重试条件：只对当前尚未确认的转场重试，不重复已经确认的消耗动作。
- 循环计数影响：按英雄处理事务定义计数，不按退出或点击计数。

### 关闭合成结果并返回列表

- 来源页面：合成结果页。
- 进入正向证据：结果标题或结果主体稳定出现。
- 允许目标页面：英雄详情页或英雄列表，以动作契约声明为准。
- 业务成功证据：结果页消失且目标页面稳定出现；不能用“已点击关闭”替代。
- 重试条件：结果页仍存在时可重试关闭；已经离开结果页时不得盲点原坐标。
- 失败诊断：保存结果页、点击后页面和最终超时截图。
- 循环计数影响：仅当本次合成结果已确认且收尾页面成立时完成事务。

## 审查清单

- 动作是否同时定义了来源页面和允许目标页面？
- 危险动作是否有 `UNKNOWN` 分支，而不是把识别失败当作安全？
- 日志中的“成功”是否都有对应的业务证据？
- 相同外观、动态动画和弹窗遮挡是否会制造假阳性？
- 重试是否保持原目标，并避免重复执行不可逆动作？
- 超时诊断能否回答“点击前是什么、点击后变了哪里、为什么没确认”？
- 轮次是否只在完整业务闭环后增加？
