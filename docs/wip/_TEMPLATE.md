# 交接单：一句话说清这次在干什么

> **这份文件是「进行中」的临时凭证，不是文档。**
> 合并进 main 之后**删掉它** —— 结论该进的地方是提交信息、`CHANGELOG.md`、
> `docs/decisions/` 或 `docs/maintenance/<路线>.md`，不是这里。
>
> 它会被自动收进 [`docs/STATUS.md`](../STATUS.md) 的「在制品」一节，
> 所以不需要再登记到 `docs/README.md` 索引里。
>
> 复制本文件 → `docs/wip/2026-11-08-arena-refresh.md`（日期 + 英文短名）。

## 一、现在做到哪一步

一两句话。用**能验证的说法**，不要写「基本完成」：说到哪一页、哪条判据、
哪次实跑退出码是多少。

## 四、下一个人第一步该干什么

```

```

## 五、坑（试过但没用的）

这一段最省时间。写清「我试过 X，结果 Y，所以别再试」。
没有就写「暂无」。
