# 英雄合成遇到 SSS 材料时转传送设计

## 目标

模拟器版英雄合成过程中，如果材料候选中出现 SSS 材料，停止当前合成，不消耗该 SSS 材料；将当前正在处理的无等级副本改走传送流程。传送完成后回到英雄列表，继续当前轮。

## 业务规则

1. 当前卡为 SSS：跳过。
2. 当前卡非 SSS 且有红点：进入刻印材料页面。
3. 材料页面出现 SSS：停止继续加材料，不启动合成。
4. 触发第 3 条时，传送目标是当前正在处理的无等级副本，不是触发判断的 SSS 材料。
5. 传送完成后不结束轮次，继续处理后续卡片。

## 流程设计

```text
英雄列表
  -> 非 SSS + 红点
  -> 刻印加材料
  -> 材料中无 SSS -> 原合成流程
  -> 材料中有 SSS -> 中止加材料
  -> 返回英雄列表
  -> 传送英雄
  -> 传送当前无等级副本
  -> 返回英雄列表并继续本轮
```

## 实现边界

- 仅增加材料区的 SSS 标记识别，模板只保留 SSS 标记，不包含英雄立绘和大面积背景。
- 新增“待传送当前副本”上下文，不能把触发判断的材料卡作为传送目标。
- 复用现有传送选择、确认、结果关闭和返回列表逻辑。
- 不改变 PC 版本现有行为；模拟器分支使用现场模板和坐标。

## 验证标准

- 单元测试覆盖：无 SSS 材料继续合成；有 SSS 材料中止合成并返回传送；传送完成后继续当前轮。
- 现场测试覆盖：真实模拟器中出现 SSS 材料时不再点击合成，传送的是当前无等级副本。
- 全量测试通过，且现场日志明确记录“中止合成 -> 传送当前副本 -> 继续本轮”。
