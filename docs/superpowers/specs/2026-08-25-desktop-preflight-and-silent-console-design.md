# 桌面版环境检测与静默子进程修复设计

## 目标

解决桌面版三个直接影响使用体验的问题：

1. 明确提示用户必须先启动雷电模拟器并进入《第七史诗》，再启动助手或执行环境检测。
2. 环境检测通过后，切换功能路线不再要求用户重复检测。
3. 自动化运行期间调用雷电控制台时不再反复弹出终端窗口。

## 行为设计

### 环境检查

“检测环境”只检查与路线无关的运行条件：Windows、雷电游戏窗口、截图画布和基础画面有效性。检测成功后，结果保存在当前桌面程序会话内，切换路线不会清除。

用户点击“开始运行”时，程序在后台自动进行一次快速复检。复检失败则不启动工作进程，并在界面显示具体原因；复检成功后再启动所选路线。这个过程不需要用户额外点击。

所选路线的模板资源仍须验证，但它属于路线启动校验，不再影响全局环境检测状态。路线资源缺失时，只阻止该路线并显示错误，不要求用户重新检查模拟器。

### 启动顺序提示

桌面界面的环境区域固定显示以下操作顺序：

> 请先启动雷电模拟器并进入《第七史诗》，再启动本助手并检测环境。

README 和用户手册同步说明该顺序。

### 静默雷电子进程

所有由助手调用的 `ldconsole.exe` 命令统一使用 Windows `CREATE_NO_WINDOW` 标志，包括实例查询、点击和返回。现有命令参数、超时和错误处理保持不变。

非 Windows 测试环境使用值 `0`，保持兼容。

## 状态与错误处理

- 路线切换：保留已通过或已失败的环境检查结果，不自动发起截图。
- 开始运行：按钮点击后先进入“正在复检”状态，禁止重复点击和路线切换。
- 复检期间切换路线：界面已禁用路线切换，不会出现校验对象变化。
- 快速复检失败：不创建工作进程，恢复控件，并显示失败原因。
- 路线模板失败：不创建工作进程，显示所选路线的资源错误。

## 验证标准

1. 控制器测试证明切换路线不会清除已通过的环境结果。
2. 界面测试证明启动前会自动复检，失败时不会启动工作进程。
3. 模板校验测试证明切换路线后所选路线仍会在启动前验证。
4. 子进程测试证明三个 `ldconsole.exe` 调用均带有 `CREATE_NO_WINDOW`。
5. 界面文案、README 和用户手册均明确启动顺序。
6. 桌面专项测试和项目全量测试全部通过。

## 非目标

- 不自动扫描磁盘寻找雷电安装目录。
- 不自动启动或关闭雷电模拟器。
- 不增加多模拟器实例选择功能。
- 不修改现有游戏业务路线逻辑。
