# 战斗内网络重连设计

## 目标

主线、竞技场和远征在已承诺战斗期间遇到“网络连接异常，请重新连接。点击重试”时，安全点击重试并继续当前战斗，不返回大厅。

## 根因

共享战斗监督器只认识模式提供的战斗、自动战斗、结算和少量白名单动作。最新竞技场现场是有效游戏画面，但三种模式均没有网络弹窗识别器，因此 45 秒后按未知画面安全停止。

## 设计

- 从最新真实截图提取“网络连接异常，请重新连接”正文和“点击重试/箭头”两个局部模板，放入 `templates/global`。
- 新建共享 `games/epic7/global_popups.py`，只有两个锚点都在各自固定区域匹配时才返回重试点击点。
- 三种模式的 `observe_battle()` 优先把识别结果映射为 `allowed_action=("retry-network", point)`。
- 共享监督器保持恢复锁；普通白名单动作仍只点一次。仅 `retry-network` 在弹窗持续存在时最多点击两次，两次之间至少等待 3 秒。
- 第二次点击后弹窗持续 15 秒仍未消失，保存 `network_retry_failed` 诊断并退出码 1；不返回大厅、不按 Back。
- 弹窗消失后清空本次重试计数，继续原战斗。若同一战斗稍后出现新的网络弹窗，重新获得两次额度。

## 验证

- 固化最新网络弹窗 fixture，并用正常战斗、结算和普通列表作为反例。
- 离线测试覆盖双锚点、缺失任一锚点不识别、三模式均暴露相同动作、最多两次、失败诊断、消失后继续及再次出现时额度重置。
- 运行全项目离线测试、编译和差异检查；真实模拟器测试仍由用户执行。
