# “辅助英雄友情点数抵达”提示兼容设计

## 问题

主线启动时可能停留在“辅助英雄友情点数抵达”全屏提示。当前导航将其识别为未知页并反复发送 ESC；ESC 只会打开退出游戏确认框，取消后仍返回该提示，最终触发 `return_home_failed`。

## 方案

1. 从失败现场提取两个固定锚点：顶部标题“辅助英雄友情点数抵达”和底部“点击关闭”。
2. 只有两个锚点同时匹配时才认为提示成立，并点击底部关闭锚点中心；虽然提示支持任意位置关闭，仍选择明确的关闭区域以降低误点风险。
3. 主线状态机优先处理该提示，返回关闭动作但不修改业务状态、自动战斗状态或完成轮次。
4. 导航在返回大厅、页面转场和等待目标页面三个阶段均可关闭该提示；仍要求连续两帧页面一致后才点击。
5. 未知页策略保持不变，不因本提示新增任何盲点逻辑。

## 边界
