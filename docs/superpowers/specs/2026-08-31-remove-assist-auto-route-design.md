# 删除助手自动路线设计

## 目标

从《第七史诗自动助手》中完整删除 `assist_auto`（助手自动）路线，使它不再出现在桌面界面、交互式启动器、CLI 模式注册和当前使用文档中，同时不影响其他路线共用的战斗自动化能力。

## 删除范围

- 删除助手自动专属业务实现 `games/epic7/assist_auto.py`。
- 删除助手自动专属模板、固定样本和路线测试。
- 从 `MODE_SPECS`、模式标签、交互式启动器和桌面路线目录中移除 `assist_auto`。
- 删除快速战斗集成测试中只针对助手自动的用例；保留主线、竞技场、远征和狗粮的共用测试。
- 更新 README、用户手册、架构、扩展说明、转场契约、待办和 PC 迁移清单等当前有效文档。
- 历史规格和历史实施计划保留原文，作为当时设计与变更记录。

## 保留范围

- 保留 `runner_base.py`、战斗监督器、自动按钮识别、快速战斗切换和体力处理等共用代码。
- 保留主线、竞技场、远征、狗粮和英雄合成对上述共用能力的使用。
- 不为旧的 `--mode assist_auto` 提供兼容别名；删除后该参数应被 CLI 明确判定为无效模式。

## 产品行为

- 桌面界面不再展示“助手自动”。
- 交互式启动器重新连续编号，不保留空缺菜单项。
- 当前路线总数从七条变为六条。
- README 和用户手册不再提供助手自动的启动命令或功能说明。

## 验证标准

1. 先修改注册表、启动器和桌面目录的测试，使其期望不存在 `assist_auto`，并确认测试因现有路线仍存在而失败。
2. 完成最小删除后，相关测试通过。
3. 全仓搜索确认当前代码和当前有效文档中不再有助手自动引用；允许历史规格与计划保留引用。
4. 运行完整测试套件、编译检查和 `git diff --check`，确认其他路线没有回归。
