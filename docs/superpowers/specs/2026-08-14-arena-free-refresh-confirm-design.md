# 竞技场免费刷新确认设计

## 问题

所有可挑战对手都失败后，状态机会点击刷新按钮。游戏随后显示“更新交战对手”确认弹窗；旧代码直接等待新列表，因此在弹窗上超时并保存 `refresh_opponents_failed`。

## 设计

- 只在同一截图中同时匹配“更新交战对手”标题、“免费”资源标志和右侧确认按钮时，才允许点击确认。
- 刷新等待器负责处理该中间弹窗；首次确认未生效且同一弹窗仍稳定存在时，最多再点击一次。
- 两次点击后弹窗仍存在，或弹窗缺少任一安全锚点时，不进行盲点，保留现场并按原有刷新失败路径安全停止。
- 点击确认后继续使用现有条件等待，直到竞技场列表出现且至少有一个可安全挑战的对手。

## 测试

- 使用 2026-08-14 的真实失败截图验证三锚点识别及确认点击位置。
- 分别移除标题、免费标志和确认按钮，验证均不产生确认动作。
- 验证确认弹窗持续存在时只点击两次；随后列表出现时刷新成功。
- 运行竞技场聚焦测试和全量离线回归。
