# 全局 P 键安全停止设计

## 目标

自动化运行期间，即使雷电模拟器位于前台，用户按一次 `P` 也能安全停止脚本。

## 设计

- 使用 Windows 原生 `GetAsyncKeyState` 检测全局 `P` 键，不增加第三方依赖。
- 在运行监督循环的每次截图或动作前检查停止信号；信号触发后不再执行后续点击。
- 对按键做边沿检测，长按 `P` 只触发一次。
- 触发时立即输出中文日志 `用户按下 P，正在中断自动化`。
- 保存当前监控帧作为诊断现场；若保存失败，仍应停止自动化。
- 主程序以退出码 `130` 结束。现有成功 `0`、资源耗尽 `2` 和故障 `1` 保持不变。
- 保留终端 `Ctrl+C` 作为备用中断方式。

## 边界

- 首版仅支持 Windows。
- 不增加悬浮窗、托盘图标、设置页面或可配置热键。
- `P` 键只在自动化进程运行期间生效，不拦截或修改游戏收到的键盘输入。

## 验证

- 单元测试覆盖：未按键继续、按下 `P` 触发一次、长按不重复触发。
- 主程序测试覆盖：手动停止返回 `130`，且不是故障退出码 `1`。
- 实机测试：启动一轮主线，在模拟器前台按 `P`，确认不再点击、终端打印原因并保存现场。
