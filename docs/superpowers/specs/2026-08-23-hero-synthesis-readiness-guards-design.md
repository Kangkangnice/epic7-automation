# 英雄合成页面就绪与结束判断设计

## 目标

修复英雄合成流程中把“页面尚未加载/内容暂未识别”误判为“材料已结束、传送卡不存在或本轮已结束”的问题。模拟器和 PC 共用状态机；本次只加强状态确认，不改变既有 SSS、红点、传送目标和合成业务规则。

## 现状与根因

- 刻印页当前以绿色按钮作为锚点；绿色按钮出现但 Up 材料暂时未被识别时，会直接发出 `start_synthesis`。
- 传送选择页当前以自动选择标签作为锚点；标签出现但高亮卡暂时未识别时，会走返回列表分支。
- 列表翻页结束当前以“下一张卡区域没有亮度内容”作为结束条件；动画或列表恢复未完成时可能提前完成轮次。
- Runner 的两帧稳定确认只能确认当前识别结果连续两帧相同，不能证明该结果代表页面已经加载完成。

## 设计

为状态机增加轻量的连续观察计数，并在动作执行后清零相关计数：

1. 刻印材料页：进入后先等待页面内容就绪；Up 材料识别到则允许点击。未识别到 Up 材料时，至少连续两次稳定观察到“绿色按钮存在、刻印页仍在、没有 SSS 材料、没有 Up 卡”，才允许 `start_synthesis`。单帧空结果只等待。
2. 传送选择页：自动选择标签存在但高亮卡未识别时等待连续确认，不直接返回。只有确认没有可传送卡且页面确实具备返回条件时才返回。
3. 列表结束：下一张卡区域为空时，要求列表主结构或评级/红点信号连续稳定后才计为本轮结束；否则等待。
4. 已有确认弹窗、SSS 材料中止、传送返回就绪判断保持不变。

## 成功标准

- 加载中/黑屏/单帧缺失不会触发 `start_synthesis`、错误返回或提前完成轮次。
- 真实夹具中的材料添加、材料已加完、SSS 材料中止、传送选择、合成确认和完整一轮流程保持原有动作顺序。
- 离线测试全通过；不启动模拟器真实测试，待离线验证完成后交给用户操作。
