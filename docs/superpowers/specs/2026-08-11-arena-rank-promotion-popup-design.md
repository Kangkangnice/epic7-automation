# 竞技场段位提升提示兼容设计

## 问题

竞技场状态机在 `CONFIRMING` 状态下可以点击既有段位确认按钮，但脚本启动时若已经停留在段位提升提示，导航层会将其识别为未知页并反复发送 ESC，最终 `return_home_failed`。

## 方案

1. 使用段位变化区域中央的绿色晋级箭头和底部“确认”按钮作为双锚点，避免仅凭通用确认按钮误点。
2. 共享识别函数返回确认按钮中心；段位名称和徽章可随段位变化，不参与匹配。
3. 导航将该提示作为可关闭的全局提示，在返回大厅、转场和等待页面时连续两帧确认后点击。
4. 竞技场状态机在 `CONFIRMING` 状态复用同一双锚点规则，保持完成轮次的现有计数逻辑。
5. 亲密度上升不在本次实现范围内，等待用户提供现场截图后再建立独立双锚点。

## 验收

- 最新 `20260811_192336_919643_return_home_failed.png` 可由导航识别并关闭。
- 最新段位提示和原有段位提示均可由竞技场状态机确认。
- 去掉晋级箭头或确认按钮任一锚点后必须拒绝匹配。
- 只运行离线测试，不启动或控制模拟器。
