# 雷电 14 渲染窗口兼容设计

日期：2026-08-10

## 目标

兼容更新后的雷电模拟器窗口，不修改模拟器设置，不重做现有主线与竞技场模板，并恢复主线实机验收。

## 已确认环境变化

- 顶层窗口标题由“第七史诗”变为“雷电模拟器”。
- 顶层窗口由旧版 1982×1132 变为约 2007×1163，外框尺寸不再稳定。
- `ldconsole list2` 仍能唯一映射雷电实例、进程和渲染子窗口。
- 游戏渲染子窗口仍为稳定的 1920×1080。

## 设计

### 安全定位

窗口定位不再只依赖标题。候选窗口必须同时满足：

1. 标题为旧标题“第七史诗”或新版标题“雷电模拟器”；
2. 窗口所属进程为 `dnplayer.exe`；
3. `ldconsole list2` 中存在且只存在一个与该 PID 对应的运行实例；
4. 实例提供唯一的 1920×1080 渲染子窗口。

任一条件不满足时安全停止，不选择任意雷电窗口。

### 截图坐标

截图只截取 1920×1080 渲染子窗口，不再截取会随版本变化的顶层外框。

为了保留现有 1982×1132 模板和点击坐标，运行时将渲染画面放入兼容画布：

- 画布大小：1982×1132；
- 游戏画面位置：`x=0..1919`、`y=52..1131`；
- 顶部 52 像素和右侧 62 像素仅作为旧坐标占位，不参与业务识别。

现有模板、识别区域和业务状态机无需改动。

### 点击坐标

业务层继续使用旧画布坐标。点击前转换为渲染坐标：

- `render_x = legacy_x`
- `render_y = legacy_y - 52`

只允许 `0 <= render_x < 1920` 且 `0 <= render_y < 1080` 的点击；标题栏和右侧工具栏区域一律拒绝。

输入继续使用雷电自带的 `ld.exe input tap`，不依赖 Windows 鼠标位置，也不关闭 PyAutoGUI fail-safe。

### 窗口前置

顶层窗口前置后不立即相信 API 返回值，而是在短时条件等待中确认目标 HWND 已成为前台窗口。Windows 错误码 0 只有在随后确认前置成功时才忽略，否则仍安全停止。

### 验证顺序

1. 单元测试：新版标题、进程校验、渲染画布、点击换算、越界拒绝、前置延迟确认。
2. 完整离线回归：现有 74 项及新增测试全部通过。
3. 底座实机：连续截图/前置 100 次无异常。
4. 导航实机：大厅与主线页往返，确认目标页后才进行下一步。
5. 主线验收：依次 1 轮、3 轮、10 轮；自动战斗必须识别开启态并观察到战斗变化。

## 非目标

- 不修改雷电分辨率、CPU、内存、ADB 或窗口设置。
- 不重做主线/竞技场模板。
- 不扩展新的日常模式。
- 不实现后台运行。

## 失败处理

- 多实例、渲染尺寸变化、窗口不唯一：保存诊断并停止。
- 点击后目标页未出现：最多重试一次，再失败则停止或执行既有的一次回大厅恢复。
- 未确认自动战斗开启：不得进入“自动战斗已启用”状态。
