# 自动化稳健性待办

本文件记录各条路线的转场稳健性、日志证据和 PC 迁移工作，供后续开发者和 Agent 接续。它不是缺陷清单：没有实机证据的内容只标记为风险或待验证，不写成已确认 Bug。

## 证据等级

- **已具备**：代码和自动化测试能直接证明；若涉及真实画面，另需实机验收记录才能声明实机支持。
- **部分具备**：已有检测、重试或诊断，但尚未形成完整的来源—目标—业务成功契约，或缺少足够实机证据。
- **待实证**：当前只能提出风险，需要补充固定截图、录屏、运行日志或可复现测试。

      |---|---|

      | `等待确认` | 点完在等目标页出现 |
      | `转场确认` | 目标页连续两帧成立、状态可以提交 |
      | `转场超时` | 等到预算用完仍未成立（**这个才是现状里用的词**） |
      | `业务成功` | 事务真的完成了（不只是画面切过去） |
      | `安全停止` | 主动收手：资源不足 / 认不出 / 票用完 |
