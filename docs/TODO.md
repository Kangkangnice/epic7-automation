# 自动化稳健性待办

## 待验证 / 缺口登记

### 扣费、兑换和不可逆操作

<a id="社区签到"></a>

- [ ] **社区签到（国服模拟器）**。补同一兑换批次前后的积分读数、实际游戏与模拟器版本、输入通道和候选修订或工件。若从签到前读余额，同时记录签到及任务入账。核清四笔回执、限购和实际扣点，再评审稳定支持。半途竖屏接力单独验收。认领入口为[待办评审](../GOVERNANCE.md)与[当前交接](wip/)。[已有实机依据](maintenance/community_checkin.md#验收证据)
<a id="竞技场购旗"></a>

- [ ] **竞技场友情点购旗**。补购旗前后友情点和旗帜数量的直接对账，采集游戏明确拒绝时的页面并核对停止行为。用实际游戏、运行环境版本和目标候选复核正常及受影响分支。[已有实机依据](SAFETY_MATRIX.md#竞技场桌面实机复核)
- [ ] **竞技场天空石购旗与金币刷新**。两端恢复支持前，先核实报价、选中状态、确认和回执，再经授权对账。另复验现有刷新选项的真实扣费与结果。
<a id="刷书签"></a>

- [ ] **刷书签**。分别对账「已提交、回执不明」和「已记购买成功、流水待核」两笔扣款。将购买与刷新回执不明路径接入原地对账，再用离线回放确认无第二次提交、无公共回大厅、无后续任务或巡检，复核取图超时。用目标候选补零刷新、已购、售罄、遮挡、同排商品及金币与天空石不足边界。[已有实机依据](maintenance/shop_refresh.md#验收证据)
- [ ] **宠物领养**。免费领养与用品均不可购买时的退出已验。在商店有可购买行时，核对目标商品、打开购买框、确认、回执、回商店，以及买满饲料后的禁用状态。
- [ ] **企鹅批量购买**。核实红叶不足或提示购买货币时能安全停止。
- [ ] **英雄合成**。连续复验外观相同的副本切换、退出满 SSS 传送、关闭合成及传送结果并返回列表，补齐两类结果遮罩的画面证据。
- [ ] **迷宫强化石**。退出商店、离开迷宫并回大厅已验。补逐笔商品、资源与购买回执，核对相似确认框只允许已选且启用的商品。复验一区「完成探险」、区域选中、地图标记和没有目标商品时的正确停手。
- [ ] **装备制作**。复验金币不足、材料不足和完成出售后退回大厅。退场失败时保留已制作数量。
- [ ] **月光剧场金币购票**。先在两端核实金币报价、可选数量、购买确认与购票后能否继续看完一集，再决定是否开放购票，以及默认设置和限额。
- [ ] **远征难度选项**。核对三个难度在选中时的画面与确认结果，再评估开放难度一、二。

### 奖励、轮次与接力

- [ ] **竞技场**。周奖刷新后复验断网遮罩解除、红点恢复读数与成功领取。补周排名奖的选中状态、不同段位的入口和稳定胜败画面。用结算日玩家页签禁用的状态复验转 NPC，并覆盖玩家战败后更换对手及冻结画面下的安全重试。
- [ ] **狗粮**。跑通关卡地图、队伍准备、战斗、结算与重新进行，确认点击未生效时可以安全重试，轮次只在结算后增加。
- [ ] **远征**。复验赛季页与普通战斗页的区分，以及列表、难度、队伍、战斗、招募和回入口的多轮闭环。确认冻结画面下如何防止延迟输入落到下一页，再决定是否启用对应护栏。
- [ ] **主线**。覆盖全局通知弹窗变体，并从界面实跑多轮，核对页面转场、关卡结果和实际轮次。
- [ ] **主线补星**。复验六章完整扫描、换章归位、快速扫描、体力购买和耗尽收尾。确认满星小节不会开打，核对篇章进度与小节绿勾冲突时的真实页面。接力后的扫描进度和完美奖励入口仍待确认。
- [ ] **支线故事**。找出能区分普通关卡和据点的可观察证据，验证半途接力和两个据点分别耗尽后能正确继续。复验无活动标记的大厅入口、其它标记位置、地图稳定和拖动范围，以及首次打首领时中级难度的选中状态。
- [ ] **月塔**。完成单轮 25 层和连续两轮，覆盖赛季入口、体力不足及默认阶段。若要增加阶段选择，先核实游戏的阶段选择页。
- [ ] **骑士团捐赠**。请求、支援和领取每周任务奖励的正常链路已验。补不同里程碑档位、额度差异及难辨认的捐赠数字，核对相近读数不会导致错捐。
- [ ] **世界首领战**。次数用完时的安全退出已验。补当前候选版本有剩余次数时的出战、结算、领奖和收尾。
- [ ] **圣域收菜**。本批次第 1 行见领取完成弹窗，第 3 行确认输入后转为倒计时，其独立领取回执待核。复验大厅入口红点、可照料状态及照料后弹窗，再核对精灵之森以外的页面。[该次日志定位](howto/route_acceptance.md#现状页的实机依据)
- [ ] **成就领取**。四分类无奖励时的巡检已验。补各类实际领奖和声望档位的效果升级弹窗。
- [ ] **活动小游戏**。活动恢复时复验长时间存活、连续多次三选一、重新进行回到首卡及连续两轮，并验证剩余操作的页面切换和安全退出。

### 共性与发布

- [ ] **异常退场**。复现装备制作完成后回不了大厅、竞技场非购买路径取图超时后无法恢复，核对输入通道、焦点和目标页。保留已完成量及待对账交易现场。
- [ ] **运行结果与现场**。核对运行横条和结果页都以本次运行的最终结果显示。连续运行时，把失败关联到对应路线和最后画面。
- [ ] **共用动作护栏**。补页面证据冲突及业务尚未确认时拦截成功的共用验证。明确未知页或缺少导航能力的例外处理与退出条件。
- [ ] **桌面候选工件**。用目标发行包复验桌面启动、任务中心、运行横条展开与停止，核对实际输入和收尾。通用打包与随包项目见[发布手册](howto/release.md)。

## PC 迁移矩阵

- [ ] **主线和每日编排**。复验第 4 章第 11 关「轻触后解锁」及可能的二次确认，跑完整桌面每日编排并确认下游任务实际运行。
- [ ] **竞技场**。补当前发布工件的正常对战闭环，并复验升级奖励弹窗的识别和安全处理。
- [ ] **圣域收菜、世界首领战**。分别实测领奖完成弹窗和结算后的领奖。
- [ ] **骑士团捐赠、英雄合成**。复验花格选中及颜色、字形变化。用 PC 免安装版复验满 SSS 的识别，以及合成、传送结果关闭后回到英雄列表。
- [ ] **支线故事**。按顺序复验活动主页、两个据点和首领难度，核对刷新倒计时原文和期次已结束提示。共享识别区域变化后同时复验模拟器。
- [ ] **月光剧场、月塔、迷宫强化石**。补剧场首幕以外的关卡、结算、三选一、票耗尽及返回入口；补月塔顶层结算；对照两端迷宫入口与已完成标记的位置差异。
- [ ] **活动剧情、活动小游戏**。补当期剧情已看完的页面与完整收尾。小游戏在活动恢复时验摇杆距离、滑动时长与全流程。
- [ ] **远征、狗粮、宠物领养、企鹅批量购买、装备制作**。补目标 PC 客户端的页面证据与实机闭环，再评估放行。
