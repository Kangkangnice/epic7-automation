# 使用手册

## 1. 安装与准备

1. 下载发布页提供的 Windows 版。免安装版解压后，打开「亚卡助手」。
2. 打开游戏并登录，选择简体中文，等游戏进入大厅。模拟器建议使用横屏 1920 × 1080，并只打开一个运行游戏的实例。
3. 在助手「任务中心」选择「安卓模拟器」或「PC 客户端」，点「检测环境」。切换客户端后重新检测。PC 客户端和助手的 Windows 权限应一致。

[查看路线和客户端支持范围](STATUS.md)

## 2. 选择并运行任务

1. 在「任务中心」勾选要执行的路线，检查右侧执行计划。**勾选顺序就是运行顺序**。想换顺序，可以取消后重新按顺序勾选。
2. 有次数输入框的路线可以调整。显示「固定次数」的按标示执行，显示「自动跑完」的按游戏内完成条件结束。活动剧情需要先把游戏停在「观看故事」页，然后单独运行。
3. 在各路线右侧打开「设置」，确认可能消耗的体力、积分及其他资源。
4. 点「开始任务」。运行时可在桌面横条看进度，点横条可返回日志；关闭主窗口也会收为横条。每条任务的结果可在「运行日志」查看。

社区签到仅适用国服模拟器。路线会从大厅打开竖屏社区，签到、浏览和分享帖子，再按设置兑换。切到 PC 模式后，该路线从任务列表和执行计划移除。其他仍显示但当前客户端不能运行的路线会在计划中标为跳过。

### 2.1 实用工具：连点器

1. 在「实用工具」中点「拾取位置」。倒计时结束时，助手记下光标所在的位置。
2. 填写点击间隔，然后点「开始连点」。换屏、改显示缩放或移动窗口后，重新拾取位置。
3. 按 P 或点「停止」结束。连点期间鼠标会回到已选位置，优先用 P 停止。

连点器只按指定位置重复点击。它与路线任务不能同时运行。

## 3. 次数与资源

| 你看到的设置 | 实际含义 |
| --- | --- |
| 可调次数 | 按各路线的结算或处理结果计数。竞技场计的是已结算场次，月塔计的是打完的楼层。 |
| 固定 1 次 | 完成一遍整项内容。比如社区签到的一次包含签到、浏览、分享和启用的兑换。 |
| 固定 2 次 | 世界首领战按游戏当日剩余额度执行，最多两场。 |
| 自动跑完 | 支线故事、月光剧场和活动剧情按当前可处理内容结束。 |
| 刷书签填 0 | 扫描当前货架并按设置用金币购买目标商品。付费刷新次数为零。 |

### 3.1 路线可选项

| 路线 | 启动前要确认 |
| --- | --- |
| 竞技场 | 检查对手来源、偏好与名单、周奖励和旗帜补充。周奖励默认钻石；旗帜不足时默认只接受 100 友情点兑换 5 面旗的报价。天空石购旗、金币刷新当前不支持。 |
| 主线、主线补星、狗粮、世界首领战、支线故事、月塔 | 体力不足时按「使用生命之叶」设置补充。上限 0 表示不限；不想消耗时请关闭该选项。 |
| 刷书签 | 购买目标商品消耗金币。默认刷新 0 次，填正数后每次付费刷新消耗 3 天空石。友情点购买默认开启，上限 10 个。 |
| 迷宫强化石 | 核对路线设置中的商品和资源选项。路线只按已确认的规则买入目标商品。 |
| 社区签到（国服） | 默认用社区积分兑换行动力和两类强化石，兑到当日限购。设置中可分别关闭行动力或强化石。 |
| 月光剧场 | 先使用免费观览；可使用持有的票。金币购票不执行。 |
| 宠物领养、装备制作 | 检查商店购买或制作后整理开关。装备出售、萃取会消耗选中的装备。 |

各路线的可用平台、次数和验收到哪一步，以[现状速查](STATUS.md)为准。

## 4. 接力、结果与停止

- **接力**：如果停在路线能识别并允许接手的页面，启动后可从该环节继续。想从头走，可以先回大厅。每条路线的接力情况见[现状速查](STATUS.md)。
- **结果**：看已确认的实际场次、奖励、购买数量和收尾情况。允许的额度用完、今日已领完等情况会按原因显示。
- **停止**：点「安全停止」或短按 P，等待界面确认结束。购买、兑换和制作回执不明确时先保留画面，查游戏内的实际结果，再决定是否重跑。
- **跑完自动关机**：每次打开助手默认关闭。启用时结束后会提示关机倒计时，可取消。主动点「安全停止」不触发自动关机。

出现识别、点击或停止异常时，先保留现场，再按[故障排查](TROUBLESHOOTING.md)处理。

社区兑换提示结果不明时，保持当前页面，先从日志找出是哪件商品，再到游戏里核对该商品的每日限购次数和积分变化。核清前暂停兑换和后续任务。正常结束时，等待助手确认已回到大厅。[社区签到验到了哪里](STATUS.md#三业务验收依据)

### 刷书签消费与对账

启动这项任务即按当前设置购买誓约书签、神秘书签和已启用的友情点数，购买花金币。友情点数默认开启，单次任务上限 10 个。刷新填 0 仍会扫一遍货架并购买；填正数才会付费换货架，每次 3 天空石。

遇到购买或刷新结果不明，立即点「安全停止」，确定本轮已结束后查日志所示商品或刷新项。核对游戏内金币或天空石变化、商品库存或货架变化，再决定是否重跑。这类失败会结束刷书签，但每日任务当前仍可能尝试回大厅和接下一项。[故障排查](TROUBLESHOOTING.md#启动与运行)
