# 亚卡助手使用手册

## 一、使用前准备

- 操作系统：64 位 Windows 10 / 11。
- 游戏：《第七史诗》，游戏语言设置为**简体中文**。
- 安卓模拟器：推荐雷电或 MuMu，分辨率设置为 **1920 × 1080（横屏）**，仅运行一个《第七史诗》游戏实例，不支持游戏多开。
- PC 客户端：正常启动游戏即可。

在 [Releases](https://github.com/Kangkangnice/epic7-arky-assistant/releases) 下载免安装版，完整解压后双击 `ArkyAssistant.exe`，无需安装其他运行环境。

> **注意事项**
>
> - 游戏窗口无需始终置于最前方，但**不要最小化游戏窗口**。
> - **任务运行期间不要手动操作游戏**，也不要调整游戏分辨率或切换账号。
> - 模拟器运行时不占用电脑鼠标；PC 客户端部分操作可能短暂占用鼠标或切换前台。

## 二、快速上手

### 1. 检测环境

打开游戏并进入大厅，再打开亚卡助手。首次使用时，阅读「使用须知」并点击「开始使用」。

在「任务中心」选择对应的运行环境（安卓模拟器或 PC 客户端），点击「检测环境」。检测通过后即可开始配置任务。

### 2. 选择任务

- 任务分为「每日」「按需」「赛季」「活动」四组，可单独勾选，也可点击分组勾选框选择整组任务。
- **勾选的先后就是执行顺序**，可根据自己的游戏习惯自由组合；如需调整顺序，取消勾选后重新选择。
- 不同运行环境支持的任务略有区别；不支持的任务会被跳过，具体以软件提示为准。

**以下任务需要单独运行，不能与其他任务同时勾选：**

| 任务 | 启动前准备 |
| --- | --- |
| 活动（小游戏） | 将游戏停在「选第一张卡」页面。 |
| 活动剧情 | 将游戏停在「观看故事」页面。 |

活动任务也不能相互组合。其他任务首次使用时，建议从游戏大厅开始。

### 3. 设置次数与参数

填写需要执行的次数。次数不可修改的任务会按其自身规则自动结束。

点击任务查看功能说明、次数含义和注意事项；有「设置」按钮的任务还可调整对手偏好、资源消耗、购买选项等参数。具体以软件内的说明为准，无需另外查阅任务清单。

**首次使用请核对任务设置及资源消耗**，尤其是生命之叶的使用上限、刷书签的刷新次数，以及涉及英雄合成、传送、装备出售或萃取等不可逆操作的选项。

<!-- 在此添加任务说明和设置界面的实机截图。 -->

### 4. 开始任务

点击「开始任务」，助手将按照勾选顺序执行任务。运行期间可通过悬浮窗口查看进度，也可返回主界面查看日志。

需要中断时，点击「安全停止」或**长按键盘 `P` 键约 0.8 秒**触发全局停止。长按设计是为了避免在其他软件中打字时误触，请稍微按住等待停止确认。**停止后请等待界面确认再手动操作游戏。**

<!-- 在此添加悬浮窗口和运行结果的实机截图。 -->

### 5. 查看结果

任务结束后，在「运行结果」查看各项任务的完成情况、耗时、收获及异常原因。下次打开助手时仍可查看上一次运行结果。

## 三、便捷功能

- **任务接续**：部分任务支持从当前游戏页面继续执行。重新开始前，请根据实际进度调整次数；不支持接续的页面可能需要先返回大厅。刚执行过购买、合成或整理时，请先核对结果。
- **刷新提醒**：任务结束后，助手会尝试读取支线故事刷新倒计时及月光剧场免费观览状态，帮助玩家避免遗漏资源。显示的是最近一次成功读取的信息，不是实时推送。
- **完成后关机**：开启后，本轮任务结束将安排电脑关机，可在 60 秒倒计时内取消。该选项默认关闭；异常结束或资源耗尽也可能触发，手动安全停止不触发。启用前请保存电脑上的其他工作。
- **QQ 消息通知**：可选功能，配置 QQ 机器人后可接收任务运行结果，不配置不影响使用。

配置步骤、接收权限及测试方法见 [QQ 消息通知配置教程](QQ_NOTIFICATION.md)。此功能依赖 QQ 平台的主动消息权限，实际能否使用以测试结果为准；手动停止不发送通知。

## 四、实用工具

在「实用工具」中可使用连点器：点击「拾取位置」，在倒计时内将鼠标移到目标位置，设置点击间隔后开始连点。**长按 `P` 键约 0.8 秒**或点击停止按钮即可结束连点。

**连点器不能与任务中心的任务同时运行。** 连点器会占用鼠标，仅按指定位置重复点击，不识别游戏画面。

## 五、遇到问题

如遇环境检测失败、任务中途停止或其他异常，请查看[故障排查与问题反馈](TROUBLESHOOTING.md)，按说明获取诊断信息并反馈给开发者。

欢迎加入亚卡助手 QQ 交流群：**173919378**，交流使用心得、反馈问题或提出功能建议。

## 刷书签消费与对账

启动这项任务即按当前设置购买誓约书签、神秘书签和已启用的友情点数，购买花金币。友情点数默认开启，单次任务上限 10 个。刷新填 0 仍会扫一遍货架并购买；填正数才会付费换货架，每次 3 天空石。

遇到购买或刷新结果不明，立即点「安全停止」，确定本轮已结束后查日志所示商品或刷新项。核对游戏内金币或天空石变化、商品库存或货架变化，再决定是否重跑。这类失败会结束刷书签，但每日任务当前仍可能尝试回大厅和接下一项。[故障排查](TROUBLESHOOTING.md)
