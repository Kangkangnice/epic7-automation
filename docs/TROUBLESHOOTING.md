# 故障排查与问题反馈

遇到问题，可先进行简单检查。如果仍无法解决，请在亚卡助手 QQ 交流群（**173919378**）反馈，无需自行分析日志或排查代码。

## 一、常见问题

| 问题 | 处理方法 |
| --- | --- |
| 检测不到模拟器 | 确认游戏已进入大厅，仅运行一个游戏实例，模拟器分辨率为 1920 × 1080（横屏），重新检测。仍失败可重启模拟器后再试。 |
| PC 客户端检测失败 | 确认游戏已启动并进入大厅。若提示权限不一致，按软件提示处理后重新检测。 |
| 开始任务按钮不可用 | 确认已阅读使用须知、环境检测通过并勾选任务，且连点器未在运行。 |
| 游戏画面无法识别 | 确认游戏语言为简体中文，窗口未最小化，游戏未卡在加载或断线页面。停止任务后返回大厅，再重新检测。 |
| 任务被跳过或无法组合 | 检查软件的任务说明及当前运行环境；活动和活动剧情必须分别单独运行。 |
| 任务提前结束 | 查看运行结果中的原因，确认体力、旗帜、金币等资源是否充足，或是否已无剩余内容。 |
| 需要停止任务 | 点击「安全停止」或**长按 `P` 键约 0.8 秒**（持续按住直到界面响应），等待任务停止。若持续无法停止，请反馈问题。 |
| 游戏更新后出现异常 | 检查是否有新版助手；暂停异常任务并反馈，不要反复尝试可能消耗资源的操作。 |

`P` 是全局停止键，需**持续按住约 0.8 秒**触发，避免打字时误触。在其他软件中短按 P 不会中断任务。

达到目标次数、无剩余内容、资源不足或手动停止，不一定是故障。部分任务从当前游戏页面接续，也属于正常行为。

**如果发现异常购买、合成、出售或萃取，请立即停止任务，核对游戏内实际结果，不要盲目重跑。**

## 二、如何反馈问题

### 1. 获取诊断信息

如果运行失败后出现诊断包提示：

1. 点击「复制提交说明」。
2. 点击「打开所在文件夹」，找到对应的 ZIP 诊断包。

如果未自动生成诊断包，可在任务停止后点击「导出诊断包」，选择相关任务导出信息。

<!-- 在此添加诊断包提示卡片的实机截图。 -->

**请尽量在问题发生后及时保存诊断信息，不要先删除日志或反复运行任务。** 如游戏仍停留在异常页面，也可额外保存一张截图。

### 2. 补充问题描述

将复制的提交说明粘贴到消息中，再补充当时发生了什么。按下面四项填写：

- 运行环境：雷电 / MuMu / 其他模拟器 / PC 客户端。
- 问题任务：填写出问题的路线名称。
- 问题描述：说明发生了什么，以及原本希望助手怎么做。
- 提交说明：粘贴软件生成的内容（如有）。

例如：使用 MuMu 模拟器刷书签，设置刷新 10 次，第 3 次时停止，游戏停在购买确认页面。

### 3. 发送给开发者

- **QQ 交流群：173919378（推荐）**。发送问题描述、提交说明及必要的脱敏截图或日志。
- [GitHub Issues](https://github.com/Kangkangnice/epic7-arky-assistant/issues)：也可在这里提交问题或建议。

诊断包可能包含游戏昵称、好友、公会或其他账号信息。**请先检查并脱敏，不要直接在公开群聊上传未经检查的完整诊断包。** 保留原始包，必要时通过私聊提供经检查的诊断信息。涉及资源损失、隐私泄露等敏感问题，请私下联系开发者，参见[安全说明](../SECURITY.md)。
