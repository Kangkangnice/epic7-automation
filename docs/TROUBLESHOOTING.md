# 故障排查

## 先保留现场

任务失败后，先看「运行日志」中的结果和最后显示的页面。购买、兑换、制作或领奖刚发生时，先查游戏中的余额、库存或次数，确认结果后再重跑。

看到失败诊断包卡片后，打开所在文件夹，按卡片上的短码找到 `E7-…-短码.zip`。这份包带有本次故障前最多五张游戏截图和日志，方便维护者看到重试或回大厅前的页面。向维护者反馈前，请检查包内是否有昵称、账号、通知或其他个人信息。需要另外收集某条路线已有的诊断材料时，可以使用「导出诊断包」。

## 启动与运行

| 看到的问题 | 可以怎么做 |
| --- | --- |
| 找不到正在运行的模拟器 | 只保留一个模拟器实例，确认游戏已进大厅。确认窗口没有最小化，横屏使用 1920 × 1080，然后重新检测。 |
| 游戏画面正常，按钮没有反应 | 先停止任务，检查游戏窗口是否有遮挡、是否存在弹窗。使用 PC 客户端时，确保游戏与助手以相同 Windows 权限运行，再重新检测。 |
| 游戏更新后出现大量页面识别失败 | 保留失败画面并导出诊断包。反馈游戏版本和受影响路线。 |
| 游戏已经转到下一页，助手仍在等待 | 保留最后的画面和日志，反馈点击前看到什么、点击后实际到了哪里。 |
| 技能动画期间暂时看不到战斗按钮 | 如果战斗仍在进行，先等画面稳定。持续无进展时，安全停止并留证。 |
| 某条路线被跳过 | 查看「执行计划」里的原因；对照[现状速查](STATUS.md)确认该客户端能否启动该路线。 |
| 路线直接从中途开始 | 开局接力是正常行为。想从头走时，先返回大厅再启动；可接力范围见[现状速查](STATUS.md)。 |
| 点击「安全停止」后还没退出 | 等待当前操作结束。如果助手提示已强行结束，游戏可能停在中间页面，先检查当前页面，再决定怎么返回大厅。 |
| 社区兑换后提示回执不明 | 保留画面，从日志确认商品。核对兑换中心的该商品限购次数和积分变化，核清前先别再次确认或重跑。 |
| 刷书签提示购买结果不明确、刷新没确认，或疑似异常扣款 | 立即点「安全停止」，保存日志和诊断包。取日志中的商品、价格或刷新时间，对照游戏内余额、库存和货架。结果待核时先别重跑。 |

## 提交有效问题现场

提供助手版本、游戏客户端、路线及选项、看到的页面、实际结果和你预期的结果。有诊断包时附脱敏包或界面短码。若游戏内可能有扣费、兑换、购买或奖励入账，请注明已核对的结果和仍不确定的部分。
