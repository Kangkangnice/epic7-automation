# 开局接力覆盖面

开局接力是指启动时停在路线中途，助手确认当前页面后，可以从这一步继续。运行中能处理某页，与开局只凭当前画面能从该页继续，是两项不同的能力。[路线总览](STATUS.md)

下表列出当前回放覆盖的接力起点和需要注意的限制。它用于维护识别器、补反例和选择实机起点。客户端的启动与验收范围以现状速查为准。路径的声明、接线和验证要求见[接力契约](TRANSITION_CONTRACTS.md#接力契约路线准入的另一半)。

| 路线 | 已有接力回放或明确限制 |
| --- | --- |
| 英雄合成 `hero_synthesis` | 从入口开始。传送选择、确认和奖励页外观相近，需要能排他的判据才可接力。 |
| 主线 `story` | 关卡和剧情入口、助手选择、队伍准备、播放与跳过确认、战斗中、通关和奖励结算。 |
| 竞技场 `arena` | 对手列表及已选中、队伍选择、战斗中、战斗结果、段位确认。购旗弹窗盖住队伍页时不按队伍页接管。 |
| 远征 `expedition` | 主页、通缉传单、难度确认、准备战斗、队伍选择、战斗中、战斗结果、招募确认和招募结果。 |
| 月塔 `tower` | 月塔主页、楼层列表、准备战斗、战斗中、失败页、结算、装置选择确认和已征服页面。 |
| 狗粮 `fodder` | 从入口开始。须先区分「重新进行」页面与战斗中画面。 |
| 支线故事 `side_story` | 首页、篇章详情、地图和场景、助手选择和队伍准备、剧情及跳过确认、通关与结算。场景页可辨认，仍需验证如何区分普通关卡与据点，以及如何保留据点阶段。 |
| 刷书签 `shop_refresh` | 秘密商店本体。购买和刷新确认弹窗不作为接力起点。 |
| 活动小游戏 `survivor` | 活动已过期。活动开放时由使用者推进到指定起点，路线没有自动接力。 |
| 活动剧情 `activity_story` | 由使用者停在「观看故事」页后启动。 |
| 世界首领战 `world_boss` | 骑士团主页、世界首领战主页、辅助队伍、队伍配置、战斗中、结算和级别奖励。 |
| 骑士团捐赠 `knights_donation` | 骑士团主页、资源支援页、每周任务页。支援确认等浮层不作为起点。 |
| 迷宫强化石 `labyrinth_stone` | 战斗菜单、迷宫列表和详情、地图、房间、商店、剧情、备战、战斗和退出相关画面可被接力探针识别。命中画面仍按路线规则处理，购买确认不作为接力许可。 |
| 圣域收菜 `sanctuary` | 圣域主页和精灵之森。领取完成弹窗不作为起点。 |
| 社区签到（国服） `community` | 从横屏入口开始。竖屏中途启动当前未提供接力。 |
| 月光剧场 `moonlight_theater` | 从入口开始。领取奖励前后分集页外观接近，接错可能进入购票确认。 |
| 成就领取 `achievement` | 成就页和获得成就奖励弹窗已有接力回放。 |
| 主线补星 `story_star` | PC 的篇章面板和小节列表。接管页面后从允许的首个篇章重新扫描，已满星小节会跳过。 |
| 宠物领养 `pet_adoption` | 宠物小屋、领养弹窗、领养结果和宠物商店。购买确认不接管。 |
| 企鹅批量购买 `penguin_purchase` | 圣域主页、精灵之森和成长祭坛。数量确认和完成弹窗不作为起点。 |
| 装备制作 `craft_equipment` | 制作页未选部位和已选部位两态。确认、结果和整理相关画面不作为开局接手许可。 |

修改接力时，在[接力回放](../tests/test_resume_contracts.py)核对实际探针、页面和状态。可确认的起点维护在本表，缺证或故障的整改维护在[待办与缺口](TODO.md)。
